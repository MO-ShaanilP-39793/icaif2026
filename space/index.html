File format

  

    
{"strategy": "my_agent",
 "decisions": [{"round_id": "holdout-2026-01-02-r1", "cash": 0.25,
                "weights": {"AAPL": 0.03, "...": "all 30 symbols"}}]}

    
Sizing. pre_fee (default) sizes each target
      on NAV before the 0.1% fee and takes the fee from cash, so a fully invested book ends
      the round with slightly negative cash. post_fee shrinks the targets so the
      fee fits. The rules state the fee but not which of the two the backend does; the
      validation receipts (Oct 8–9) will show it. The difference matters only near 100%
      invested.

    
One entry per round, rounds 1–7 (09:30–15:30 ET). Half-days have rounds
      1–4 only. cash must equal 1 − Σweights to within 1e-9. The file is
      rejected for a round that doesn't exist, a duplicate round or a wrong symbol set.
      A missing round, or a weight that breaks a rule (over 0.30, a total over 1, float
      dust), holds the round the way the backend would, and is listed. Every window
      restarts from $1M in cash and replays the same decisions.
