# ICAIF 2026 holdout leaderboard

Prospective strategies for the ICAIF 2026 trading-agent competition, ranked on held-out
2026 data the way the contest ranks them: per 15-day window, on the mean rank of return,
Sharpe, maximum drawdown and turnover.

This page is read-only. It ships the ranking code, three reference strategies' results,
and the submitted entries' metrics. It ships no prices and no decisions files. Entries
are submitted from the team's private scorer and recorded in a private dataset; this
Space holds the copy the page reads.

Built by `tools/build_holdout_space.py` in the icaif2026 repo; don't edit here.
